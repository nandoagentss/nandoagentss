# Convierto modelos de negocio en software.

Soy **Nando, creador de algoritmos de negocio**. Conecto estrategia, producto,
datos y desarrollo para transformar decisiones operativas en sistemas que
se pueden ejecutar, explicar y mejorar.

Mi enfoque aplica a proyectos de distintas industrias, con especial interés en
**marketplaces**: cómo conectar oferta y demanda, definir precios, asignar recursos
y construir confianza entre participantes.

## Qué diseño y desarrollo

- **Algoritmos propios del negocio:** reglas de precios, elegibilidad, prioridad y asignación.
- **Software conectado:** modelos de datos, integraciones y procesos que comparten una fuente de verdad.
- **Operaciones autónomas:** flujos con estados claros, trazabilidad y recuperación ante fallos.

## Del modelo a la operación

| Pregunta de negocio | Cómo la traduzco a software |
| --- | --- |
| ¿Cómo se crea y entrega valor? | Modelo, actores, incentivos y recorridos del producto. |
| ¿Qué determina una decisión? | Variables, restricciones y reglas explícitas y versionadas. |
| ¿Cómo se mantiene la coherencia? | Contratos compartidos, datos confiables y controles de concurrencia. |
| ¿Cómo sabemos que funciona? | Pruebas reproducibles, evidencia y límites documentados. |

La IA amplía mi capacidad de construir. Las decisiones críticas del sistema
se sostienen en reglas y controles que se puedan revisar.

## Un caso que puedes poner a prueba

### [Business Algorithms Engine →](https://github.com/nandoagentss/business-algorithms-engine)

**Caso de ejemplo: marketplace de servicios, inspirado en los retos de [Soy Pro](https://soypro.vip).**

Una implementación pública de referencia que conecta solicitudes, precios,
una DB de profesionales y reservas transaccionales. El ejemplo usa perfiles,
ubicación, disponibilidad y nivel Súper Pro para mostrar cómo se traducen
las condiciones de un negocio a decisiones de software.

**27 pruebas reproducibles**, con conflictos reales entre conexiones SQLite
y un recorrido completo con datos sintéticos.
